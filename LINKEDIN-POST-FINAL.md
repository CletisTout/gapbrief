## 📱 MAIN POST TEXT

Die meisten GEO-Dashboards zeigen dir eine Zahl: „Ihr Visibility ist 44 % im Topic X."

Hilft das weiter? Nicht wirklich.

Weil die wichtigste Frage **nicht beantwortet wird**: Auf *welcher einzelnen Query* verliert ihr? Und *wie* gewinnt die Konkurrenz genau auf dieser Query?

Das ist das Problem mit Durchschnitts-Metriken im GEO: Sie verschleiern die Prompts, die tatsächlich wichtig sind.

**Für die Peec MCP Challenge habe ich deshalb GapBrief gebaut** — einen Claude-Code-Skill, der Peec-Gap-Daten in **publish-reife Content-Briefs** übersetzt. Nicht eine weitere Metrik. Sondern ein actionables Dokument, das ein Content Writer *Montag morgens umsetzen kann*.

GapBrief macht drei Dinge, die andere GEO-Tools nicht tun:

1. **Multi-URL Content-Analyse**: Scraped die Top-3 Konkurrenz-URLs pro Gap + dekonstruiert ihre Content-Struktur (H2-Gerüst, FAQ-Muster, Entity-Nennung, E-E-A-T Signale). Der Brief zeigt nicht nur, dass ihr fehlt — er zeigt, *wie die Konkurrenz gewinnt*.

2. **Search Intent Mapping**: 6–10 echte User-Queries pro Gap. Nicht geraten. Direkt aus den Peec-Daten extrahiert, mit Prompt-Frequenz-Gewichtung.

3. **7-Tage-Validation Loop**: Nach Publication wird Peec automatisch erneut abgefragt. War der Gap tatsächlich geschlossen? Mit Lift-Messung + Bericht.

**Das Ergebnis:** Ein Markdown-Brief mit adaptiver H2-Struktur (10–14 Sections je nach Impact), Entity-Checkliste, FAQ-Template aus Competitor-Patterns, Schema-Empfehlungen (Article, FAQPage, Comparison), modellierter Lift-Forecast.

Alles: CLI-first Python. Cron-ready. Batch-fähig für 50+ Gaps pro Nacht. MIT-lizenziert. Installierbar mit einer Zeile.

**Neu:** Interaktives Dashboard mit **Tech Innovation Theme** für visuelle Gap-Präsentation — ranked nach Impact, mit Competitor-Daten, ready for Stakeholder-Meetings.

Ob Agentur oder In-House: Wer Peec nutzt, kann das in unter 5 Minuten auf eigene Projekte anwenden. Finance, Pharma, FMCG, Tech, Retail — spielt keine Rolle. Vertical-agnostic. Forking welcome.

## 💡 TALKING POINTS (for Comments)

**If asked "What's the technical stack?"**
> Python 3.11, Peec MCP for gap data, Firecrawl for competitor content scraping, Claude Sonnet 4 for brief generation, MIT license. Works as Claude Code skill or standalone CLI.

**If asked "Can I use this for [my vertical]?"**
> Yes, absolutely. GapBrief is vertical-agnostic. It works with any Peec project in any industry. The pipeline is designed to be forked and adapted.

**If asked "How does the 7-day validation work?"**
> validate_lift.py runs automatically 7 days after content publish. It re-queries Peec API for the same prompts and measures if visibility actually improved. Full lift report with before/after metrics.

**If asked "How is this different from [competitor tool]?"**
> Most tools stop at "you have a gap." GapBrief closes the gap: it analyzes *how competitors win* on those gaps (content structure, entities, search intent), then gives you a ready-to-execute brief. Plus: open source, no SaaS, fully reproducible, extensible.
